# アストラルパーティー PvE(協力チャレンジ)の基本ルール

判断に必要なルールだけを要約したもの。出典は各wiki(astralparty.miraheze.org / wikiwiki.jp/tenoujigaoh)と攻略note。
数値はアップデートで変わることがある。画面に表示されたテキストと食い違う場合は画面を優先する。

## 勝敗と進行
- 4人で協力し、ボスのHPを0にすれば勝ち。画面上部の進捗バーが上限に達すると負け。
- プレイヤー4人が順に行動 → 敵が行動、で1ラウンド。ラウンド終了ごとに進捗+1。
- 画面左上の「Round」と、画面上部中央の「進捗バー」は別の数字。ラウンドボーナスは Round、マップイベントやイベントマスの抽選は進捗バーが基準。
- プレイヤーが倒されても進捗+1。倒されたキャラはそのターンと次のターンを失う。復活までは攻撃もバフも受けない。
- 進捗バー上のマップイベント(敵の増援、強化、ボス出現など)は事前に確認できる。
- ミッション(画面上部の「！」)を達成すると、チップやボス弱体化などの報酬がある。
  ボスを殴る前に弱体化ミッションを終えるのが基本(例: 夢想号は海賊精鋭2体撃破でガオーの防御-6)。

## ターンの流れ
- 自分のターンでは、カード使用(通常1枚)とスキル使用を好きな順で行い、そのあと移動ダイスを振る。カードとスキルはダイスを振る前にしか使えない。
- 移動ダイスは10面(1〜10)+移動補正。戦闘のダイスは6面。敵も基本的に1〜10マス動く。
- 移動中に敵のいるマスを通ると戦闘を仕掛けられる。ショップと強化チップショップは通過でも利用できる。それ以外のマスは止まったときだけ効果がある。
- 手札上限は8枚。超過分はターン終了時に捨てる(呪いカードを捨てる手段になる)。
- 3の倍数のラウンドにラウンドボーナス(普通・困難は6コイン、悪夢以上は5コイン、+スターライトスタック数)とカード。
- 初期手札は普通・困難が6枚(効果3/バトル3)、悪夢以上は4枚(効果2/バトル2)。

## 戦闘
- 攻撃合計 = 攻撃力 + 6面ダイス + 攻撃カードの上昇値。防御合計 = 防御力 + 6面ダイス + 防御カードの上昇値。バトルカードはダイスを振る前に選ぶ。
- ダメージ = max(1, 攻撃合計 - 防御合計)。防御をいくら上げても最低1ダメージ。
  → HP1の敵はカードなしで必ず倒せる。HP1の自分は防御しても倒れる。
- 被ダメ+1(マーク、狂暴など)や被ダメ軽減(ヘルメットなど)は上の計算のあとに適用。
- バトルカードにはコストがあり、1戦闘で使える合計コストはスターレベル0で3、レベルアップごとに+1(最大6)。
  - 攻撃(中) コスト1 +1〜3 / 攻撃(大) コスト2 +1〜6 / 攻撃(特大) コスト3 +1〜10
  - 防御(中/大/特大)も同じ値
  - シャドウアタック コスト2 +3・反撃無効 / 名刀：ガオー切り コスト4 +1〜20 / チャージ コスト5 +5・会心の一撃を得る
  - 会心の一撃 コスト3 +6、さらに最終的な攻撃値を1.5倍(切り捨て) / 龍の咆哮 コスト3 +4・反撃無効・敵に防御-4と移動-9
  - 噛みつく コスト2 覚醒1つにつき攻撃+1(最大4)・反撃無効
- 回避: 攻撃側のダイス目を見てから「防御」か「回避」を選ぶ。
  回避は攻撃側より大きい目で成功(攻撃側6なら6で成功)してダメージ0。失敗すると防御0で攻撃合計をそのまま受ける。
  成功率は攻撃側の目 1→5/6、2→4/6、3→3/6、4→2/6、5→1/6、6→1/6。
- 敵は基本的に防御してくる。回避してくる敵はごく一部(金ちゃん、キャンディピニャータ)。
- 反撃持ちの敵は、こちらが攻撃して倒しきれないと殴り返してくる。
- 敵は基本的に最初に遭遇したプレイヤーにだけ戦闘を仕掛ける。ただしそのマスに複数人いれば全員を攻撃する。
  ほとんどの敵は矢印の方向へ進む。一部は特定プレイヤーを追跡する。
- 自分の移動中に敵のいるマスを通ると、戦うかスルーするか選べる。ダイス移動なら複数の敵と順に戦える。

## スターレベル
- コイン15/20/25でレベル1/2/3。自分のスタートポイントとセーフティポイントは通過時にも止まってレベルアップできる。
  他人のスタートポイントはちょうど止まったときだけ使える。
- レベルアップでステータス上昇、バトルコスト上限+1、チップ1枚、上位レアリティのチップ出現率アップ。1回の停止で上がるのは1レベルだけ。
- コイン入手: 敵の撃破、金儲けマス、ラウンドボーナス、振込み、キャラ/チップの効果。

## マス
- ショップ: 通過/停止で買い物(カード3コイン、3枚陳列)と振込み(自分の5コインを味方1人へ。5コイン未満では不可)。ちょうど止まるとカード1枚。
- 強化チップショップ: 通過/停止でチップを買える。1回目10コイン、以降5コインずつ値上がり。
- モンスター突撃ゲート: 好きな敵のマスへ移動し、戦うか選べる(向きはその敵と同じ)。
- モンスター: 敵が出現し戦闘するか選ぶ。リカバリー: HP2回復。疾走: もう一度ダイスを振って進む。
- カード報酬: カード1枚。金儲け: コイン。災厄: ダメージ。全員イベント(イベントマス): ランダムイベント発生。
- スタート/セーフティポイントに止まるとHP2回復。

## チップ
- レベルアップ、ミッション達成、チップショップで3択から1枚選ぶ。同じチップは1人1枚まで。
- レアリティは青<紫<金。抽選率(青/紫/金):
  - 普通: Lv0-1 60/30/10、Lv2 40/40/20、Lv3 20/50/30
  - 困難以上: Lv0-1 60/37/3、Lv2 40/45/15、Lv3 25/50/25
- レベルアップ/チップショップでは一番左の枠がキャラのクラス(支援/生存/攻撃/カード)に寄り、Lv0-1は青、Lv2は紫、Lv3は金が出やすい。
- 属性は 無/スターライト/マーク/ヒール/チャージ。同じ属性を取るとその属性が出やすくなる。
  無以外の属性を2種類取ると、残り2種類は以後出なくなる(属性の固定)。
- スタック:
  - マーク(敵に付与): 被ダメ+1。何個あっても+1。敵の行動終了ごとに-1。数を参照するチップ(イーグルアイ、忍術手裏剣など)がある。
  - ヒール(味方に付与): ターン開始時にスタック数だけ回復し、ターン終了時に半減。倒れると全て失う。カッターナイフで火力に変換できる。
  - スターライト: ラウンドボーナスのコインがスタック数だけ増える。減らない。
  - チャージ: 最大10。溜めるチップと消費するチップを揃えて初めて機能する。
- PvEレベルを育成済みのキャラはチップの再抽選(リフレッシュ)ができる。回数に限りがある。

## 効果カード(主なもの)
- チョコレートケーキ: 2回復 / ハンバーガー: 4回復 / 華奢な奢り: 味方1人の周囲3マス全員を3回復
- リモコンダイス: 次の移動の出目を1〜6で指定(移動補正は無視される)。通常の10面ダイスで6以上が出る確率は50%
- ロードブロック: 10マス以内に設置、そこを通るキャラは止まる(ちょうど止まりたいマスに置く)
- 早すぎるおんな: 味方1人の次の移動が10面ダイス2個(2〜20、11前後が出やすい。1マスだけ進むことはできなくなる)
- あなたもどうぞ？: 自分と味方1人がカードを1枚ずつ得る
- 支援: 味方1人のマスへワープ(向きは相手と同じ)
- 王の力: HP-4、3ターン攻撃+5 / 狂暴: 10マス以内の1人に2ターン攻撃+3・被ダメ+1 / 不動明王: 2ターン防御+6
- 毒で毒を制する: 2ダメージ受け、2ターンの間毎ターン3回復
- 対モンスター用レーザー: 6マス以内に3ダメージ / 対モンスター用ブリック: 3マス以内に5ダメージ
- 軌道レールキャノン: 5マス以内に6ダメージ / 定方向発破: 6マス以内の敵とその周囲2マスに4ダメージ
