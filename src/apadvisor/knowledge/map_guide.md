# マップ別の攻略データ(PvE)

日本語wiki(wikiwiki.jp/tenoujigaoh)のマップページの表と攻略、攻略noteを要約したもの。
進捗イベントの「全敵 攻+1防+1」は、その時点の敵とその後に出る敵すべてが恒久的に強化されること。
ミッションの品質は報酬チップの抽選率(青/紫/金)。数値はアップデートで変わることがあり、画面が正。

## 夢想号
- 敵: ザコ 泥棒・海賊サメ / エリート 海賊精鋭・サメタラシ(狂気以上) / ボス 海賊王ガオー
- 進捗イベント(狂気): 1 海賊サメ4体 / 3 海賊王ガオーが強化チップショップに出現 / 5 海賊精鋭2体、全敵 攻+1防+1 /
  9 ガオーが動き出す、全敵 攻+1 / 12 海賊精鋭2体とサメタラシ、全敵 攻+1防+2 / 18 敗北。
  極限は1でサメタラシも出て、13で精鋭とサメタラシ、17で敗北。悪夢は13で海賊サメ4体・全敵 防+1、20で敗北。
  困難・普通は精鋭が進捗6、ガオー始動が11、最後の増援なし、20で敗北。
- ミッション: 海賊サメ4体(チップ 60/37/3) / 海賊精鋭2体(チップ 40/45/15、ガオーの防御-6) / 海賊サメ9体(チップ 25/50/25、進捗-1)
- 要点:
  - 精鋭2体撃破までボスは放置(防御-6前に殴っても通らない)。ガオーは進捗9まで動かないが、殴れば反撃する。
  - 進捗5の精鋭までは稼ぎの時間。狂気なら精鋭が出るまでにサメ3体以上を倒しておきたい。
  - サメタラシは毎ターン敵1体にトライデント(攻+1防+1)を付けるので、早めに倒す。
  - 精鋭は叩かれるたび攻撃+1(最大+3)で、サメを呼ぶ。反撃なしで殴れるキャラ(ナンシー、ルカ、メガス、リンのライフ・ブック)が有効。
  - ガオーの一斉砲撃はHPが最も高いプレイヤーに4ダメージ(同値なら手番の早い方)。
  - ショップはマップ下側に固まっていて、強化チップショップのある上側にはない。左右対称で、中央からセーフティポイントに入るとモンスターマスを避けにくい。

## 幽魂路地
- 敵: ザコ 泥棒・さるのびっくり箱 / エリート さるの助手君・ゴリフランケンちゃん・キャンディピニャータ /
  中ボス 人工生命体(天崩→厄兆→混乱と変化) / ボス ドクター・マサオシュタイン
- 進捗イベント(狂気): 1 ドクター・天崩・助手君・びっくり箱2体 / 4 助手君・びっくり箱3体 / 7 ピニャータ2体、全敵 攻+1防+1 /
  10 ゴリフランケン・びっくり箱2体、全敵 攻+1防+1。
  天崩を倒した次のラウンドに「全員集結！」(ゴリフランケン・助手君、全敵 防+1)、厄兆を倒した次のラウンドに「満月の夜」(ゴリフランケン2体・助手君、全員の改造+2、全敵 防+1)。
- ギミック: 「改造」デバフ。改造中はびっくり箱からの被ダメが減る一方、ゴリフランケンには攻撃+3で殴られ、回復される。
  改造は怪奇飴(怪奇飴のガチャガチャで5コイン: 支援タイプのガム・頭が良くなるグミ・エナジーバー)で解除する。
  ボスはバフ「深層改造」の間は戦闘も対象指定もできず、人工生命体を倒すたびに深層改造が減る。
- 要点:
  - 助手君は近くの改造されていないキャラに改造+3を配って回るので最優先で倒す(ミッションの高品質抽選も助手君絡み)。
  - キャンディピニャータは自分から殴ってこない。回避は1/2で、失敗時の反撃が痛い。カードを使わないと倒せないなら放置でよい
    (狂気で攻撃力6以上なら、回避に失敗したとき確実に倒せる)。
  - 満月の夜で全員が改造されるので、高難易度は怪奇飴を温存する。
  - 耐久(ヘルメット、バッファーシールド、救急箱)を確保。コマチは専属カード(怪奇飴)の複製が強い。
- 出現位置は盤面データの「敵の出現位置」を参照。

## 御魂の祭
- 敵: ザコ 泥棒・氷刻青霊・凶暴赤霊 / エリート 刀剣霊・長戟霊(極限はサムライの化身-戮・怨も) / ボス 天王寺雅央
- 進捗イベント(狂気): 1 天王寺雅央が中央、氷刻青霊2体 / 3 青霊2・赤霊1、雅央が動き出す / 6 刀剣霊・長戟霊、全敵 攻+1防+1 /
  10 オール・フォー・ワン(残っている刀剣霊・長戟霊は消滅し、1体ごとに雅央のHP+36・攻+1防+1。全敵 攻+2防+2) /
  12 残りの霊を消して刀剣霊2・長戟霊1を追加、全敵 攻+1防+1 / 16 刀剣霊・長戟霊 / 19 敗北。
  悪夢はオール・フォー・ワンが11(HP+27)、13で霊追加、20で敗北。困難・普通はオール・フォー・ワンなし。
- ミッション: 氷刻青霊4体(60/37/3) / 刀剣霊+長戟霊 合計2体(40/45/15) / 合計5体(25/50/25、進捗-1)
- 霊の効果: 刀剣霊1体ごとに雅央の防御+2、長戟霊1体ごとに攻撃+2。どちらも倒すと雅央に最大HPの10%のダメージ。
  長戟霊は毎ターン7マス以内でHPが最も高いプレイヤーに2ダメージ+赤き呪い(3ターン毎ターン1ダメージ)。
- 要点:
  - 雅央にはなるべく触らず、刀剣霊・長戟霊の撃破にリソースを集中する。オール・フォー・ワンまでに倒し切るのが鍵
    (残すと雅央が強化され、霊が持っていたコインも消える)。
  - 上下の小路に入ると抜けるのに時間がかかる(方向選択、支援、早すぎるおんな、ドロシーのスキルで回避)。敵も同じなので、雅央を小路に誘導できれば安全。
  - 極限は霊を3体倒すたびにサムライの化身を呼ぶ。戮の方が強いので、刀剣霊より長戟霊を先に倒す方がよいことが多い。

## 水郷古鎮
- 敵: ザコ 爆竹ゲロゲロ・泥棒 / エリート 雰囲気系ロボ・機械蛇龍 / ボス 獅子舞いガオー+指揮センター(HP共有)
- 進捗イベント(狂気): 1 雰囲気ロボ1・爆竹ゲロゲロ3 / 3 獅子舞いガオーと指揮センター / 5 ロボ1・機械蛇龍2、全敵 攻+1防+1 /
  9 ロボ2・蛇龍1、全敵 攻+1防+1 / 16 敗北(悪夢17、困難18、普通20。困難・普通は5が爆竹ゲロゲロ3体)。
- ミッション: 爆竹ゲロゲロ4体(60/37/3) / 9体(40/45/15) / ロボ+蛇龍 合計4体(狂気・悪夢。25/50/25、進捗-1。困難・普通は2体)
- 要点:
  - ボスは獅子舞いガオーと指揮センターのどちらを殴ってもよい(HP共有)。指揮センターは通常戦闘できず、毎ターン足元に爆竹ゲロゲロを呼ぶ。
    指揮センターは必ず3マス動き、ダメージを受けるたびにそのラウンドの被ダメ+1。
  - 雰囲気系ロボは周囲4マスの敵を攻+1防+1(2回まで)する。機械蛇龍は近くの敵に防御+9の盾を付ける。
    爆竹(カード)は盛り上がりを消し、1ターン反撃を封じる。ボスのバフに注意して、余裕があれば爆竹で消す。
  - 爆竹ゲロゲロは4マス以内でHPが最も高いキャラに攻撃力ぶんのダメージ。
  - 極限は合体した獅子舞ガオーが8ラウンド目(またはHP188到達)で登場。三連爆竹ゲロゲロの範囲攻撃が脅威。

## 異変図書館
- 敵: ザコ 魔法のティーポット・変なティーポット・泥棒・大怪盗 / エリート 看守・グリーティーポット・ゼリーウィザード / ボス ゴクチョー
- 進捗イベント(全難易度共通): 1 ゴクチョー・看守・魔法のティーポット3体 / 4 グリーティーポット3体・大怪盗、全敵 攻+1防+1 /
  7 看守・ゼリーウィザード2体・大怪盗 / 10 看守・ゼリーウィザード2体、全敵 攻+1防+1 /
  真相発覚(ラウンド8、または手がかり4つ): 罪証が最も多いプレイヤーが【真犯人】になり、ゴクチョーが大幅に強化され復活しなくなる。
- ミッション: 魔法のティーポット3体(60/37/3) / グリーティーポット2体(40/45/15) / 大怪盗2体(40/45/15) / 看守3体(25/50/25、進捗-1)
- 手がかり(5つ): ゴクチョーを3回撃破 / 看守を1回撃破 / ミッション3つ達成 / 全員のスター合計7 / 誰かの罪証が4以上。
  2つで看守が復活しなくなり、4つで真相発覚が早まる。真相発覚後は手がかり1つごとにゴクチョーが20ダメージ・防御-2・移動-1。
- 罪証: 看守・グリーティーポット・ゴクチョーを倒すと付く。真相発覚前のゴクチョーと看守は罪証を持つプレイヤーしか殴らず、
  罪証1つにつき攻撃力+1。グリーティーポットは殴ったプレイヤーの罪証を奪って強くなる。
- 真犯人: 被ダメ+2、攻撃+2・移動+2・カード使用+1。敵を多く倒すアタッカーがなりやすく、倒されやすくなる。
- 要点:
  - 真相発覚前はティーポットを処理するWave。ゴクチョーと看守には安易に触らない(殴らなければ大した敵ではない)。
  - ゴクチョーは倒すたびに強化されて復活し、その強化は真相発覚後にも残る。倒すなら手がかりのために3回、そうでなければ0回。
  - 看守は累計5ダメージを受けると全員を殴るようになる。倒すビジョンがないまま攻撃しない。
  - 高難易度はゼリーウィザード(反撃なし、毎ターン5マスより外でHPが最も高いキャラに3ダメージ)の処理が勝敗を分ける。
    サポーターも殴って素早く倒す。看守はその後でよい。
  - 虫眼鏡(罪証1つにつき攻防+1)はアタッカーに強い。真相発覚後のゴクチョーの反撃対策にエアバッグやアドレナリンも有効。
- 出現位置は盤面データの「敵の出現位置」を参照。

## 魔法学院
前半は共通で、最初のイベントでスイーツ場(魔法のティーポット3体)かチクリ場(ゼリーガーディアン2体)かが決まる。
ゼリーファイターを倒すと全員+6コインで後半へ。
- 敵: ザコ 泥棒・魔法のティーポット(・変なティーポット) / エリート ゼリーガーディアン・ゼリーウィザード /
  中ボス ゼリーファイター / ボス 天王寺雅央(スイーツ場は学院長代理、チクリ場は学院警備官)
- 進捗イベント(狂気): 1 ゼリーファイターとティーポット3体(スイーツ)またはガーディアン2体(チクリ) /
  4 ゼリーウィザード・ガーディアン、全敵 攻+1防+1 / 10 ガーディアン2・ウィザード2、全敵 攻+1防+2 / 16 敗北。
- ゼリー系は「ダメージを受けるとき防御-2」。効果カードやスキルで防御を下げてから殴るのが理想。
- ゼリーファイターは1ラウンドの間にダメージを受けないと攻撃+1。毎ラウンド誰かが削る。
- ゼリーウィザードは前半なら出現位置が固定。待ち伏せしてカードやスキルで一気に倒す。
- スイーツ場(学院長代理): 雅央は5マス以内の魔法のティーポットを吸収して攻防+1、吸収できないとターン終了時に最大HPの10%を失う。
  ティーポットを残さないことが雅央を弱らせる。熱雷で早く呼ぶとティーポットを食べられる。
- チクリ場(学院警備官): 毎ターン近いキャラに「この人です」(呪いカード)を配る。使うと相手に問題生徒を付けて自分は3コイン、
  手札に残すとターン終了時にHP-1。警備官は問題生徒を追いかけて攻撃+2で殴る。
  ショップでカードを買って手札上限で「この人です」を捨てるのが対策。後半に入る前に手札を6枚以上にしておくとよい。
- ミッション(スイーツ): ゼリーファイター(全員+6コイン、後半へ) / ガーディアン3体 / ティーポット8体(進捗-1) / ガーディアン2体。
  (チクリ): ゼリーファイター / ガーディアン4体 / ウィザード3体(狂気) / ガーディアン2体。

## 龍宮遊園地
- 敵: ザコ 泥棒・蟹兄ぃ(・海賊サメ・金ちゃん) / エリート コエデカフグ・ムキムキフグ・蝦兄ぃ / ボス 天川真夢梓 または 天川蒼鯉
- 進捗イベント(狂気): 1 カニトラップ起動、蟹兄ぃ4・コエデカフグ・ムキムキフグ / 9 蟹兄ぃ3、全敵 攻+1防+1 / 16 敗北(普通18)。
  フグ2体を倒すと投票。支持しなかった方が真ボスとして登場する(真夢梓支持→蒼鯉戦+金ちゃん、蒼鯉支持→真夢梓戦+蝦兄ぃ)。
  ボスのHPを半分以下にした次のラウンドに増援(金ちゃん3体、または蝦兄ぃ2体)。
- カニトラップ: ラウンド終了時、ラウンドを4で割った余りが1なら0列、3なら8列(盤面の端の列)にいるプレイヤー全員に2ダメージ
  (2026-07-01に確認された狂気の仕様。以前は偶数ラウンド)。フグ2体撃破で終了。
- ミッション: フグ2体(40/45/15、カニトラップ終了) / 蟹兄ぃ6体(40/45/15) /
  蒼鯉戦: 金ちゃん3体(40/45/15)・6体(進捗-1)、蒼鯉の金鱗を11以上(金鱗0+無限の蛇) /
  真夢梓戦: 蝦兄ぃ2体(40/45/15)・4体(進捗-1)、ひょうたん4個(真夢梓に30ダメージ+陰陽鯉)
- 要点:
  - ムキムキフグ(移動しない、反撃あり)を先に倒す。コエデカフグはムキムキが倒れるまで反撃しないので、その間に削っておき、反撃を持ったら即倒す。
    先にコエデカフグを倒すとムキムキフグが攻撃+3で動き出す。
  - 蟹兄ぃは反撃しないが、ダメージを受けるたび攻撃+1。大ダメージを出せないなら殴らない(半端に殴って育てない)。
  - コインが少ないマップ。初手で強化チップショップに届いても買わない。サポーターのレベルアップの優先度が高い。
  - 蒼鯉戦: 金ちゃん(回避して反撃する)を倒さないとボスの金鱗(1つにつき攻防+1)が増え続ける。
  - 真夢梓戦: 5マス以内のプレイヤーの効果カードを捨てさせ、手札4枚未満なら3ダメージ。ダメージを受けるたび逆鱗(攻+2、被ダメ-2)が付くが、
    一度に21以上与えると逆鱗が0になる。ひょうたんを集めて陰陽鯉(反撃無効、攻撃ダイス6固定)を狙う。

## 龍星の中庭
- 敵: ザコ 泥棒・お出迎え係(・爆竹ゲロゲロ) / エリート センズル係・ニワトリ係・クジャク係・オシドリ係 /
  ボス ヒメ(孔雀)・ヒメ(鴛鴦)・ダーク・フェニックス
- 進捗イベント(共通): 1 卵2個・ニワトリ係・お出迎え係3体 / 7 センズル係2・お出迎え係2、全敵 攻+1防+1 / 16〜19 敗北。
  ニワトリ係を倒すとクジャクルート、卵を2個集めるとオシドリルート、どちらかを満たすとフェニックスルートも選べる(投票)。
  各ルートでボス登場や増援があり、そのたびに全敵 攻+1防+1。
- ミッション: お出迎え係3体(60/37/3) / センズル係2体(40/45/15) / ルートごとにクジャク係・オシドリ係の撃破(40/45/15、25/50/25)
- 要点:
  - 敵の大半が反撃持ちで能力も高く、厄介な状態異常をばらまく。狙いを分散させない。進捗を戻す手段が神兵天降しかないので、1回の撃破され(進捗+1)が重い。
  - オシドリ係が付ける「鴛鴦連理」(攻防-1)は、ほかの鴛鴦連理持ちと合流(通過・ワープ)すると解除できる。優先して解除する。
  - クジャクのギミックは回復した回数の勝負。ヒールスタックで回復回数を稼ぐと有利。クジャクのデバフを非アタッカーに引き受けさせる手もある。
  - センズル係は3マス以内の全員に2ダメージを与えてスタート位置へ戻す(悪夢以上)。
  - エリートの鳥が落とす「彩りの羽」(5マス以内にワープ+HP3)は強力。誰に持たせるか考える。
  - 序盤のチップはせいぜい2〜3個で精鋭と戦うことになる。コンボの完成より精鋭対策を優先する。

## 予選運動場・トーナメント運動場・決勝大会場(イベントマップ)
- プレイヤーは3人。アベレーション(ランダムな特殊効果)が付く。マムシやドロシーは不利になりやすい。
- 審判長エイミーは、殴られるまで戦闘に参加せず、殴られるとダメージを受けるようになる。序盤は無視した方がよい。
- 予選は魔法学院に近い(ゼリーファイターを毎ラウンド殴る、ゼリーウィザードを素早く倒す、ティーポットを残さない)。
- トーナメントは龍宮に近い(ムキムキフグを先に倒す)。
- 決勝はマインドのスタックが重要(1つにつきテックジャイアントガオーとマインドエアシップへの攻撃+2)。マインドを減らすメカ監視員には近寄らない。
  マインドエアシップは3ラウンドごとに召喚され、遠距離攻撃と反撃を持つ。最初の個体は6〜7ラウンド目までに倒したい。
- 盤面データはない。
