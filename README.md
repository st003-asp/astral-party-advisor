# astral-party-advisor

『アストラル☆パーティー』のPvE(協力チャレンジ)を録画し、あとから「この場面はこうするのが最善だった」を
教えてくれる解析ツールです。将棋や麻雀の解析AIの、アスパ版を目指しています。

- 画面の読み取りと総合判断は Claude(Anthropic の API)
- サイコロや撃破率などの確率は Python が厳密に計算(暗算させない)
- 判断基準は wiki と攻略note をもとにした知識ベース

> 非公式のファンメイドツールです。ゲームの運営・開発元とは関係ありません。

## はじめての方へ(Windows・プログラミングの知識なしで使う手順)

Python や API を触ったことがなくても、ダブルクリックとドラッグ&ドロップだけで使えるようにしてあります。
最初の準備に30分ほど(wikiデータの取得を待つ時間は別)、あとは録画を放り込むだけです。

### 必要なもの

- Windows のパソコンと、Steam版のアストラルパーティー
- Claude の API利用料(従量課金)。狂気13ラウンドの1試合で約4ドルでした(→ [費用について](#費用について))
  - ChatGPT や Claude の月額プランとは別の料金です。使った分だけ、前払いしたクレジットから引かれます

### 準備(最初の1回だけ)

1. **Python を入れる**
   <https://www.python.org/downloads/> の黄色いボタンからインストーラーをダウンロードして実行します。
   最初の画面で **「Add python.exe to PATH」にチェックを入れてから** 「Install Now」を押してください。

2. **このツールをダウンロードする**
   このページ上部の緑色の「Code」ボタン →「Download ZIP」。ダウンロードしたZIPを右クリック →「すべて展開」で、
   好きな場所(例: ドキュメント)に展開します。

3. **APIキーを用意する**
   1. <https://platform.claude.com/> でアカウントを作ります
   2. 「Billing」でクレジットを購入します(5ドル程度から。まずは最小額で十分です)
   3. 「API Keys」→「Create Key」でキーを作り、表示された `sk-ant-` で始まる文字列をコピーします
      (この画面を閉じると二度と表示されません。他人には見せないでください)

4. **`setup.bat` をダブルクリックする**
   展開したフォルダの中にあります。必要な部品が自動でインストールされ、最後にメモ帳が開きます。
   `ここにAPIキーを貼り付けて上書き保存` の部分を、3でコピーしたキーに書き換えて、上書き保存して閉じます。

   > 「WindowsによってPCが保護されました」と出たら、「詳細情報」→「実行」を押してください。

5. **`fetch_wiki.bat` をダブルクリックする**
   カードやチップ、敵の説明を wiki から取ってきます。1時間以上かかるので、放置しておいてください。
   (これを省いても動きますが、カードや敵の効果を調べられないぶん講評が雑になります)

### リプレイを録画する

1. ゲームのホーム画面 → プロフィール →「リプレイ」から、解析したい試合を選びます。
2. 参加者4人の名前が並んでいる画面(「再生」ボタンがある画面)で、**Win + Alt + R** を押して録画を始めます。
   この画面に出ている二つ名から、全員の使用キャラを自動で判定します。
3. 1〜2秒待ってから「再生」を押します。
4. 再生が始まったら、次の設定にします。
   - 再生速度は **2倍** まで(4倍は速すぎて読み取れません)
   - 視点が手番のプレイヤーを追うようにする
   - 画面下の再生バーは、左端の「∧」で畳む(手札が隠れないようにするため)
5. 試合が終わったら、もう一度 **Win + Alt + R** で録画を止めます。
   動画は「ビデオ」→「キャプチャ」フォルダに保存されます。

### 解析する

1. 録画した動画ファイルを、`analyze.bat` の上に **ドラッグ&ドロップ** します。
2. 黒い画面が出て質問されるので、順に答えます。
   - **プレイヤー名** … 画面左に並ぶ4人のうち、自分の表示名
   - **難易度** / **マップ** … リプレイ選択画面から録画していれば自動で読み取るので、そのまま Enter
   - **3手番だけ試すか** … 最初は `3` と入力するのがおすすめ。費用と内容を確認できます
3. 終わるとブラウザでレポートが開きます。黒い画面の最後に、今回かかった費用の目安が表示されます。
4. 全部解析するときは、同じ動画をもう一度ドラッグ&ドロップして、最後の質問で何も入力せず Enter。
   済んだ手番は飛ばして、続きから解析します(二重に課金されません)。

### うまくいかないとき

| 症状 | 対処 |
|---|---|
| `Python が見つかりませんでした` | Python のインストール時に「Add python.exe to PATH」にチェックを入れ忘れています。入れ直してください |
| `APIキーが無効です` | `.env` をメモ帳で開き、`ANTHROPIC_API_KEY=` の後ろにキーが正しく貼られているか確認します(前後に空白や「」を入れない) |
| `APIエラー(400)` で「credit balance」と出る | クレジットの残高不足です。Claude Console の Billing で追加します |
| `対象プレイヤーが見つかりませんでした` | プレイヤー名の入力が画面の表示と違います。メッセージに出ている名前のどれかを入力してください |
| `再生バーが見つかりませんでした` / 手番の区間が0個 | リプレイ再生の録画ではないか、画面の一部しか録画されていません。ゲーム画面全体を録画してください |
| 途中で止まった・ウィンドウを閉じてしまった | 同じ動画をもう一度ドラッグ&ドロップすれば、続きから再開します |

## 何を判断するか

| 場面 | 判断 |
|---|---|
| 自分の手番 | どのカードを使うか / 分岐でどちらへ進むか / スキルを使うか、対象は誰か |
| ショップ | どのカードを買うか / 誰に振り込むか(振り込まないか) |
| チップ購入マス | 買うかどうか |
| チップ入手時 | どれを取るか / リフレッシュするか |
| 戦闘(攻撃) | どの攻撃カードを使うか、そもそも殴るか |
| 戦闘(防御) | 防御か回避か / どの防御カードを使うか |

実際に選んだ行動も読み取り、`最善 / 許容 / 疑問手 / 悪手` で評価します。
評価は「選んだ時点での妥当性」で、出目の結果ではありません。

**レポートの例**: <https://st003-asp.github.io/astral-party-advisor/sample-report/>
(狂気・異変図書館・13ラウンドの1試合を解析したもの。プレイヤー名は伏せてあります)

## しくみ

```
リプレイ再生の録画(mp4)
  ─▶ 一定間隔でフレームを抽出(OpenCV)
  ─▶ 手番プレイヤーの立ち絵(または再生バーのアイコン)で手番ごとに区切る(画像処理だけ。APIは使わない)
  ─▶ 録画の冒頭から、参加者4人の使用キャラ・マップ・難易度を読み取る(Claude)
  ─▶ それぞれが誰の手番かを1回ずつ読み取る(Claude)
  ─▶ 手番ごとに、画面の内容が変わったフレームを最大20枚選ぶ(画像処理だけ)
  ─▶ 自分の手番と敵の手番を、手番単位で講評(Claude + 計算ツール + 知識ベース + 盤面データ)
      前の手番で止まったマスを次の手番に引き継ぎ、現在地を追いかける
  ─▶ report.html / report.md
```

助言のとき、Claude は次のツールを呼び出して数値を確認します。

| ツール | 内容 |
|---|---|
| `attack_odds` | 攻撃カードの組み合わせごとの撃破率・期待ダメージ・反撃で受ける被害 |
| `defense_odds` | 「防御(+防御カード)」と「回避」それぞれの倒される確率・期待ダメージ |
| `move_odds` | あるマスにちょうど止まれる確率 / 通過できる確率 |
| `route_odds` | 盤面データを使い、分岐のどちらへ進むと何%でどのマスに止まるか、ショップやセーフティポイントを通れるか |
| `locate_tile` | 止まったマスの種類(「セーフティポイント」など)から、現在地の候補を盤面データで絞る |
| `chip_odds` | スターレベル別の青/紫/金の出現率、チップショップの価格 |
| `event_tile_odds` | イベントマスで何が起きるか(有志の実測1472回) |
| `lookup` | カード・チップ・敵・マップの説明を wiki データから引く |

## セットアップ(コマンドで操作する人向け)

上の「はじめての方へ」の手順を、コマンドで行う場合の説明です。

Python 3.10 以上が必要です。

```bash
git clone https://github.com/st003-asp/astral-party-advisor.git
cd astral-party-advisor
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux は source .venv/bin/activate
pip install -e ".[dev,scrape]"
```

1. **APIキー**: [Claude Console](https://platform.claude.com/) でキーを発行し、プロジェクト直下に `.env` というファイルを作って
   `ANTHROPIC_API_KEY=発行したキー` と1行書きます(環境変数 `ANTHROPIC_API_KEY` に設定してもかまいません)。
   `.env` は Git に含めない設定になっています。
   確率計算(`apadvisor calc`)だけならキーは不要です。
2. **wikiデータ(任意だが推奨)**: カードやチップ、敵、マップの説明を引けるようにします。

   ```bash
   python scripts/scrape_wiki.py        # 日本語wiki。アクセス制限が厳しく1時間以上かかる(中断しても再開できる)
   python scripts/scrape_mediawiki.py   # 英語wiki・中国語wiki。数分で終わる
   ```

   取得した本文は `data/` に保存され、Git には含めません(wiki の文章は各執筆者の著作物のため)。
   画面に出るのは日本語名なので日本語wikiが主で、英語・中国語wikiは敵の難易度別ステータスや
   チップの正確な効果文を補う位置づけです。
   日本語名と英語・中国語のページ名の対応表(`src/apadvisor/knowledge/name_map.json`)があるので、
   日本語名で引くと対応する英語・中国語のページも一緒に返ります。

   ```bash
   python scripts/build_name_map.py verify   # 対応表を3つのwikiの数値と照合する
   ```

   wiki同士で敵のステータスなどが食い違うことがあります(更新時期の差)。食い違うものは「高い方」を採用した
   補正表(`stat_overrides.json`、`build_name_map.py reconcile` で生成)を優先し、ゲーム画面と違えば画面が正です。

## 使い方

### 録画を解析する

ゲーム内のリプレイ再生を録画した動画を渡します。Windows なら Xbox Game Bar(Win+Alt+R)で録画でき、
動画は `C:\Users\<ユーザー名>\Videos\Captures` に保存されます。

```bash
cd C:\path\to\astral-party-advisor
.venv\Scripts\activate
apadvisor analyze "C:\Users\<ユーザー名>\Videos\Captures\録画ファイル.mp4" --player hogehoge --me ミサキ --difficulty 狂気 --map 異変図書館
```

- 動画の場所は、コマンドの最初に書くファイルのパスで指定します。パスに空白があるときは `"` で囲みます。
- `--player` … 講評する対象プレイヤーの表示名(画面左のプレイヤー一覧に出ている名前)。`--order 3` のように手番順でも指定できます。
- `--me` … そのプレイヤーの使用キャラ。リプレイ選択画面から録画していれば自動で判定されるので不要です。
  その画面が写っていない録画では指定してください(見た目からは判定しません)。
- `--difficulty` / `--map` … 難易度とマップ名。敵のステータスや盤面データを引くのに使います。
  リプレイ選択画面から録画していれば、「再生」を押した直後の結果画面から自動で読み取るので不要です。
- `--model` … 使うモデル。既定は `claude-opus-5-5`。`claude-sonnet-5-5` にすると費用は半分ほどになります(→ [費用について](#費用について))。

結果は `reports\<動画の名前>\report.html` にできます(`--out` で変更可)。ブラウザで開いてください。
途中で止めても、同じコマンドをもう一度実行すれば続きから再開します。
同じ動画を別の設定でやり直すときは、`--out` で別のフォルダを指定するか、前回のフォルダを消してください。

そのほかのオプション:

- `--frames-only` … フレーム抽出と手番の区切りだけ行う(APIを呼ばないので無料)。先に確認できます
- `--max-turns 2` … 最初の2手番だけ講評する(お試し用)
- `--skip-enemy-turns` … 敵の手番(防御/回避の講評)を省いて費用を抑える
- `--start 60 --end 600` … 動画の一部だけ解析する
- `--note "潜在解放済み"` … 画面から分からない情報を伝える
- `--frames-per-turn 20` … 1手番の講評に使う画像の最大枚数。長い手番で取りこぼしがあれば増やす(費用も増える)
- `--interval` … フレームを見る間隔(秒)。既定は0.5秒

録画のコツ:

- リプレイ選択画面(参加者4人の二つ名とプレイヤー名が並ぶ画面)が写っている状態から録画を始め、1〜2秒おいて「再生」を押す。
  二つ名から全員の使用キャラを自動で判定します(このとき `--me` は不要)。
- 再生速度は等倍〜2倍にする。4倍速だと戦闘の画面が一瞬で、カードやダイスを読み落としやすくなります。
- 視点が手番のプレイヤーを追う設定にし、再生バーは畳む。こうすると手番プレイヤーの手札とステータスが全部見えます。
  (再生バーを出したまま・視点固定の録画も解析できますが、対象プレイヤーの手札が見えません)

プレイ中の画面をそのまま録画した動画は `--mode live` で解析します(選択待ちの画面を探して助言する方式)。

### レポートを人に見せる形で書き出す

プレイヤー名を「プレイヤーA」などに置き換え、画像の名前が出る場所(左のプレイヤー一覧、上部の帯)を塗りつぶしたHTMLを作ります。
APIは使いません。

```bash
apadvisor export reports\録画の名前 --dest 書き出し先のフォルダ
```

公開する前に、名前が残っていないか自分の目で確認してください。

### スクリーンショット1枚に助言をもらう

```bash
apadvisor advise screenshot.png --me ルル --difficulty 悪夢
```

### 確率計算だけ使う(APIキー不要)

```bash
# 敵(攻撃力6)の出目が2。自分は防御2・HP5、手札に防御(中)
apadvisor calc defend --enemy-atk 6 --die 2 --def 2 --hp 5 --cards "防御(中)"

# 攻撃力3で 防御2・HP6 の反撃持ち(攻撃力5)を殴る。どのカードを使うか
apadvisor calc attack --atk 3 --enemy-def 2 --enemy-hp 6 --cards "攻撃(中),攻撃(大),シャドウアタック" --cost 3 --enemy-atk 5 --my-def 1 --hp 6

# 6マス先に届く確率(移動ダイスは10面)
apadvisor calc move --distance 6 --bonus 1

# 悪夢・スターレベル2でのチップ出現率
apadvisor calc chips --level 2 --difficulty 悪夢

# 進捗バー3のときにイベントマスを踏むと何が起きるか
apadvisor calc event --progress 3
```

## 費用について

Claude API は従量課金で、講評する手番の数にほぼ比例します(動画の長さではありません)。
実行が終わると、使ったトークン数と定価換算の金額が表示されます。

| モデル | 1手番あたり | 備考 |
|---|---|---|
| Claude Sonnet 5.5 | 約0.3ドル(実測) | `analyze.bat` はこれを使います |
| Claude Opus 5.5 | Sonnet の約2倍(単価からの計算) | コマンドで `--model` を省いたときの既定 |
| Claude Haiku 4.5 | Sonnet の半分以下 | 画面の読み違いが多く、おすすめしません |

- 1試合ぶんの実測(Sonnet 5.5): 狂気・13ラウンドの試合(2倍速で19分の録画)で **4.07ドル**
  (クレジット残高が 13.36 → 9.29 ドルに減少)。自分の13手番で判断52件を講評し、解析にかかった時間は約25分でした。
  1手番あたり約0.31ドルです。
- ツールが最後に表示する金額は、キャッシュ書き込みの料金を高めに見積もっています(この試合では約4.8ドルと表示)。
  実際の請求は表示の8〜9割程度でした。
- 15〜18ラウンドなら、手番の数に比例して5〜6ドル程度の見込みです。
- 最初は3手番だけ解析して、金額と内容を確かめてください(`analyze.bat` の最後の質問で `3`、コマンドなら `--max-turns 3`)。
- フレームの抽出と手番の区切りは自分のPCで行うので無料です(`--frames-only` で確認できます)。
- `--skip-enemy-turns` で敵の手番の講評を省くと、そのぶん安くなります。

## 前提にしているルール

- 戦闘: 攻撃合計 = 攻撃力 + 6面ダイス + カード、防御合計も同様。ダメージ = max(1, 攻撃合計 − 防御合計)
- 回避: 攻撃側の出目より大きい目で成功(攻撃側が6なら6で成功)。失敗すると防御0
- 移動: 10面ダイス + 移動補正。リモコンダイスは1〜6を指定
- チップのレアリティ抽選率、チップショップの価格(10 → 15 → 20…)、レベルアップ費用(15/20/25)

知識ベースは `src/apadvisor/knowledge/` にあります。アップデートで数値が変わったら、ここを直してください。

- `rules.md` … ルールの要約
- `strategy.md` … 場面ごとの判断の指針
- `characters.json` … 35キャラの要約
- `event_tile_stats.json` … イベントマスの実測データ
- `name_map.json` … 日本語名 ↔ 英語名 ↔ 中国語名の対応表(`scripts/name_map_seed.py` から生成)
- `stat_overrides.json` … wiki間で食い違う数値を高い方に寄せた補正表
- `maps.json` … マップの盤面(マスの種類とつながり、スタート位置と最初の向き、敵の優先方向と出現位置)。
  日本語wikiのマップページの表から `scripts/build_maps.py` で生成し、マスの種類ごとの数を英語wikiと照合しています

## 制限事項

- 画面の読み取りは Claude の画像認識に頼っています。小さい文字や演出中の画面は読み違えることがあり、
  そのときは「読めなかった点」としてレポートに出ます。
- 盤面データがあるのは 夢想号・幽魂路地・御魂の祭・水郷古鎮・異変図書館・魔法学院(スイーツ場)・龍宮遊園地・龍星の中庭 です
  (日本語wikiに盤面の表があるマップ)。それ以外のマップでは、分岐の判断は画面に映っている範囲が前提になります。
- 現在地は「前の手番で止まったマス + 出目や止まったマスの表示」から推定しています。画面には周りの数マスしか映らず、
  倍速の録画では出目が写らないことも多いので、外れることがあります。確信が持てない手番では分岐を「判定不能」にします。
- 画面外の敵の位置は分かりません。
- ゲームのルールを完全に再現したシミュレータではありません。キャラ固有の効果は知識ベースの記述をもとに Claude が解釈します。
- 判断の指針は攻略記事のセオリーに基づくもので、唯一の正解ではありません。
